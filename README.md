# C# Management Systems Collection

Overview

This repository contains a collection of five C# console-based management systems developed to demonstrate important object-oriented programming, collections, generics, exception handling, records, interfaces, and file-handling concepts.

The projects are based on practical scenarios including finance, healthcare, warehouse inventory, student grading, and inventory data management.

The main goal of these applications is to demonstrate how C# programming concepts can be combined to build modular, reusable, type-safe, and reliable applications.
